# ISUCON学習ログ

日々の学習内容と、後から参照したい知識を記録する。

## 構成

```text
daily-log/
├── README.md
├── daily/       # 日ごとの学習記録
├── topics/      # 後から参照するテーマ別メモ
└── templates/   # 記録用テンプレート
```

## 運用

- 学習日は短くても`daily/YYYY-MM-DD.md`を残す
- 調べた文章のコピーではなく、自分の言葉で説明する
- 繰り返し参照する内容だけ`topics/`へ整理する
- 分からなかったことと次に試すことを必ず残す
- チーム全員に有用な手順はチームリポジトリへ還元する
